보존·교환 형식의 선행사례와 재배포 조건이 적힌 규약·정책·법령의 원문 위치를 안내합니다. 별도 조사(2026-10-09)에서 옮긴 내용이며, 상태 열은 해당 조사가 기록한 확인 수준입니다. 이 저장소에서 다시 검증한 결과는 아닙니다.

표의 버전·배포일·확인 상태는 기록된 조사 시점의 정보입니다. 현재 판본에 적용할 때는 원문과 대상 판본을 다시 대조합니다.

## 1. 보존·교환 포맷 선행사례

핵심 규정 본문을 직접 읽은 자료는 BagIt과 OCFL입니다. 나머지는 인덱스·소개 페이지·검색 결과 등 확인한 범위가 제한돼 있으므로 각 메모를 함께 살펴봅니다. 접근 실패만으로 문서의 폐쇄·로그인 필요 여부를 단정하지 않습니다.

아래 목록은 형식의 채택이나 추천을 뜻하지 않습니다. 메모의 라이선스가 명세·문서의 이용 조건인지 소프트웨어의 조건인지 구별하며, 그 형식으로 보존하는 게임·음원의 이용 조건과도 구별합니다.

| 자료                                                                                                                                   | 상태 | 메모                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------------------------------------------------------------------------------------------------------------------------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [BagIt, RFC 8493](https://www.rfc-editor.org/rfc/rfc8493.html)                                                                         | 확인 | IETF의 BagIt 1.0(2018-10, Informational) 문서입니다. 묶음은 bag(`data/` + 태그 파일)으로 표현합니다. 매니페스트 경로는 bag 기준 상대 경로이며 `/`로 구분하고 외부 참조를 금지합니다. 해시 알고리즘은 닫힌 목록이 아니며 이름은 소문자·영숫자로 정규화합니다. 도구는 SHA-256·SHA-512를 지원해야 하며 새 bag에는 SHA-512를 권고합니다.                                                     |
| [OCFL 1.1](https://ocfl.io/1.1/spec/)                                                                                                  | 확인 | 명세 날짜는 2022-10-07, 갱신일은 2024-11-07이며 라이선스는 CC BY 4.0입니다. storage root > object > `v1`, `v2` 버전 디렉터리 구조를 사용합니다. 콘텐츠 주소는 `sha512`·`sha256`만 사용하며 `sha512`를 권장합니다. 추가 fixity는 `md5 sha1 sha256 sha512 blake2b-512`입니다. 경로는 `.`·`..`를 금지하고 대소문자를 구별합니다. `inventory.json`(UTF-8)과 다이제스트 sidecar를 사용합니다. |
| [RO-Crate 명세](https://www.researchobject.org/ro-crate/specification)                                                                 | 부분 | 인덱스에는 1.3이 long term release, 1.2가 stable로 함께 표시돼 있습니다. 명세 라이선스는 Apache-2.0이며 핵심은 JSON-LD 메타데이터 문서입니다. 묶음 단위·해시 규정은 본문을 읽지 못해 미확인입니다.                                                                                                                                                                                       |
| [ISO 14721 (OAIS)](https://www.iso.org/standard/87471.html)                                                                            | 부분 | 2025-03 제3판이며 139쪽입니다. 장기 보존 아카이브의 참조 모델이며 직렬화·해시 규정은 공개 개요에서 확인하지 못했습니다(전문 미열람). CCSDS 650.0-M-3은 검색 결과만 확인했습니다.                                                                                                                                                                                                         |
| [MAME software list](https://docs.mamedev.org/contributing/softlist.html)                                                              | 부분 | MAME 0.289의 지침 문서입니다. list > `software`(배포된 완전한 묶음) > `part`(장착 매체 하나) 구조를 사용합니다. DTD(`softwarelist.dtd`)는 본문을 읽지 못해 체크섬 필드 규정은 미확인입니다. MAME 전체의 라이선스는 GPL-2.0-or-later입니다.                                                                                                                                               |
| [No-Intro 제출 안내](https://wiki.no-intro.org/index.php?title=Submitting_dump_info) · [Redump 다운로드](http://redump.org/downloads/) | 부분 | 덤프 검증용 DAT를 다룹니다. No-Intro 안내는 dump 정보 XML에 "proper specification이 없다"고 적고 있습니다. DAT-o-MATIC에서는 접근 차단 메시지를 확인했습니다. 라이선스·최신 DAT 버전은 미확인입니다.                                                                                                                                                                                     |
| [SWHID 구현 문서](https://docs.softwareheritage.org/devel/swh-model/persistent-identifiers.html)                                       | 부분 | 문서판은 1.6(2021-04-30), scheme version은 1입니다. 해시는 SHA-1(`sha1_git`)로 **고정**됩니다. 승인 명세 1.1(2023-11-06)은 본문을 읽지 못했습니다.                                                                                                                                                                                                                                       |
| [Frictionless Data Package](https://datapackage.org/standard/data-package/)                                                            | 부분 | v2가 current로 표시돼 있습니다. `datapackage.json`과 `resources`로 구성합니다. 선택 `hash`는 기본 MD5 의미이고 다른 알고리즘은 `sha1:` 같은 접두사를 사용합니다. 게임·미디어 보존 사례는 미확인입니다.                                                                                                                                                                                   |
| [Internet Archive item 메타데이터](https://archive.org/developers/items.html)                                                          | 부분 | item은 식별자 아래의 파일 묶음이며 `<identifier>_meta.xml`과 `<identifier>_files.xml` sidecar를 사용합니다. 해시 필드는 `md5 sha1 crc32`입니다. 문서 라이선스·파일명 규범은 미확인입니다.                                                                                                                                                                                                |

### 비교할 때 구별할 역할

목록의 자료는 서로 다른 역할을 다룹니다.

- 파일 묶음의 저장·전송 규약: BagIt
- 버전 이력을 포함한 저장 배치: OCFL
- 아카이브의 책임과 기능에 대한 참조 모델: OAIS
- 매체 단위의 목록: MAME, No-Intro/Redump
- 객체 식별자: SWHID

이는 역할에 따른 구분이며, METS 2 기반 스키마를 대체하거나 보완할 수 있다는 평가가 아닙니다.

## 2. 재배포 조건의 원문 위치

규약·정책·법령에서 조건을 찾아볼 위치를 모았습니다. 확인 범위는 주로 조항 번호·제목·URL·게시일이며, 조건의 해석이나 문서 사이의 충돌 여부는 판단하지 않았습니다. 게시·개정일도 대부분 미확인입니다.

이 목록은 재배포 허용 여부의 판정이나 법률 자문이 아닙니다. 어느 문서의 어느 절을 확인해야 하는지 찾는 출발점으로 사용합니다.
