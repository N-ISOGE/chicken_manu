## 문서 읽는 법

조사·조직화·보존에서 사용하는 자료는 출처의 확인 수준을 함께 적습니다. 조사 시점과 적용한 형식·프로그램의 판본도 함께 살펴봅니다.

| 표기   | 뜻                                           |
| ------ | -------------------------------------------- |
| 확인   | 기록에 명시한 범위의 원문을 직접 열어 확인함 |
| 부분   | 일부만 읽었거나 요약 도구의 결과에 기댄 것   |
| 미확인 | 근거를 찾지 못했거나 열지 못함               |

‘확인’은 해당 기록의 열람 범위를 뜻합니다. 원문을 읽은 것, 소스를 대조한 것, 프로그램을 실행한 것은 각각 구별해 기록합니다. 별도 조사에서 옮긴 확인 상태는 이 저장소에서 다시 확인한 결과와 구별합니다.

기술 검토의 판정은 **채택·시험 후 채택·보류·회피**로 구별합니다. 출처를 확인했다는 사실만으로 기술의 채택이나 구현의 검증이 끝났다고 읽지 않습니다.
