# 공통 — 프로젝트와 문서의 공통 안내

프로젝트의 목적과 용어, 문서를 읽고 작성하는 방법, 현재 결과와 남은 일을 안내합니다. 조사·정리·보존에서 함께 사용하는 출처와 작업 기록도 여기에서 찾아볼 수 있습니다.

## 문서 읽는 법

출처의 확인 수준은 다음과 같이 구별합니다. 조사 시점과 적용한 형식·프로그램의 판본도 함께 살펴봅니다.

| 표기   | 뜻                                         |
| ------ | ------------------------------------------ |
| 확인   | 원문을 직접 열어 확인함                    |
| 부분   | 일부만 읽었거나 요약 도구의 결과에 기댄 것 |
| 미확인 | 근거를 찾지 못했거나 열지 못함             |

기술 검토의 판정은 **채택·시험 후 채택·보류·회피**로 구별합니다. 출처를 확인한 것, 프로그램을 실행한 것, 설계나 기술을 채택한 것은 각각 구별해 읽습니다.
