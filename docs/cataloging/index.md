# 조직화 — 매체와 관련 자료를 목록화하고 보존 형식 마련하기

[← 길라잡이][project-guide]

매체와 관련 자료를 목록화하고, 보존에 사용할 기록 구조와 형식을 마련합니다. 무엇을 하나의 대상으로 기록할지 정하고, 이름·식별 정보·판본·관계를 기록해 찾아볼 수 있게 합니다. 자료의 저장 위치와 식별 정보를 구별하고, 목록과 관계를 보존할 수 있도록 데이터 포맷과 메타데이터 스키마를 정의합니다.

## 1. 대상 목록화하기

매체와 관련 자료의 역할을 구별하고, 무엇을 하나의 대상으로 목록에 올릴지 정합니다. 조사에서 파악한 채보 단위와 자료 참조를 바탕으로 기록할 범위를 살펴봅니다.

- [길라잡이의 기록과 활용][guide]
- [포맷별 채보 단위와 파일 참조 필드][units]

## 2. 식별 정보와 관계 기록하기

목록에 올린 대상의 이름·식별 정보·판본과 서로의 관계를 기록합니다. 저장 위치와 대상의 식별 정보를 구별하고, 매체와 관련 자료를 함께 찾아볼 수 있도록 연결합니다.

- [스키마와 식별자][schema]

## 3. 보존에 사용할 형식 마련하기

목록과 식별 정보, 자료 사이의 관계를 보존할 데이터 포맷과 메타데이터 스키마를 정의합니다. 기존 보존·교환 형식과의 대응을 살펴보고, 필요한 정보를 담을 수 있는지 검토합니다.

- [스키마와 식별자][schema]
