# 조사 — 매체의 형식과 명세를 파악하기

[← 길라잡이][project-guide]

어떤 매체가 존재하고, 무엇으로 구성되며, 프로그램이 어떻게 해석하는지 살펴봅니다. 조사한 형식과 단위, 해석 규칙은 기록·보존 방법을 정할 때 근거로 사용합니다.

## 1. 조사 대상 파악

어떤 매체와 형식이 있는지 파악하고, 조사할 범위와 형식별 비교 질문을 살펴봅니다. 존재를 기록하는 발견 목록과 접근 가능한 자료에 따른 상세 조사 순서를 구별합니다.

- [조사 대상 파악][formats]
- [상용·모바일·VR 포맷 후보][commercial]

## 2. 명세와 구성 확인

공개된 명세에서 매체의 구성과 단위, 관련 자료를 참조하는 방식을 확인합니다. 문법으로 표현한 내용도 함께 살펴봅니다.

- [포맷별 채보 단위와 파일 참조 필드][units]
- [BMS 문법][grammar]

## 3. 프로그램의 해석 방식 확인

프로그램이 매체를 어떻게 읽고 처리하는지 살펴보고, 명세와 구현 사이 또는 구현마다 다른 점을 비교합니다.

- [BMS 파서 구현 정리][parsers]

## 4. 출처와 추가 조사 사항 정리

조사한 내용의 출처와 확인 수준을 기록하고, 더 확인할 사항을 모읍니다. 새로 확인한 내용은 앞 단계의 조사 범위와 설명에 반영합니다.

- [포맷별 추가 확인 사항][checks]
- [참고 자료][references]
